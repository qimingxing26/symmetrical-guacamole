# My Site PRD v1

> 本文档用于说明你要做什么。第一版先不要讨论技术栈。

## 1. 项目一句话说明

My Site 是一个带评论功能的个人主页。主人是一个写代码、写文章、拍照片的个人开发者，主页按分类展示作品（项目、文章、摄影），访客可以在每件作品下发表评论，管理员可以按作品筛选和删除评论。

主人的个人介绍：

```text
在代码的严谨里造梦，在书页的留白处思考，用镜头捕捉人间，用笔尖还原文火。
```

## 2. 项目目标

这个项目希望完成：

- 展示个人信息：所在地、座右铭、社交链接（GitHub、邮箱）。
- 分类展示作品：项目作品 2-3 个、文章 2-3 篇、摄影 2-3 组。
- 每件作品有独立的评论区，访客可以围绕作品展开讨论。
- 管理员可以按作品筛选评论、查看评论时间、删除不合适评论。

## 3. 目标用户

### 访客

访客是网友、朋友、同学、老师。他们打开网站时想要：

- 浏览和借鉴项目作品。
- 欣赏文章。
- 查看拍摄的照片。
- 对感兴趣的作品发表看法。

### 管理员

管理员就是你自己。你需要在后台：

- 按作品筛选评论（方便聚焦某个作品下的讨论）。
- 查看每条评论的发布时间。
- 删除不合适的评论。

## 4. 核心使用场景

用几句话描述用户怎么使用这个网站：

- 访客打开首页，看到个人介绍（一句话介绍、所在地、座右铭、社交链接）。
- 访客按分类浏览作品列表（项目、文章、摄影）。
- 访客点击作品卡片，进入作品详情页阅读/查看完整内容。
- 访客在作品详情页的评论区填写昵称和内容，提交评论。
- 评论提交后立刻展示在评论区。
- 管理员进入后台登录页面，输入账号密码登录。
- 管理员在评论管理页按作品筛选评论，查看评论时间。
- 管理员对不合适评论点击删除，二次确认后删除。

## 5. MVP 功能范围

第一版必须完成：

- 首页展示个人介绍（一句话介绍、所在地、座右铭、GitHub 链接、邮箱）。
- 首页按分类展示作品列表（项目、文章、摄影），每个分类 2-3 件作品。
- 作品详情页展示作品完整内容。
- 作品详情页展示该作品的评论列表。
- 访客可以在作品详情页提交评论（昵称 + 内容）。
- 评论提交后可以直接展示。
- 管理员可以登录后台。
- 管理员可以按作品筛选查看全部评论。
- 管理员可以看到每条评论的发布时间。
- 管理员可以删除评论（删除前二次确认）。

## 6. 页面清单

第一版页面：

- 首页（个人介绍 + 分类作品列表）
- 作品详情页（作品内容 + 评论区）
- 管理员登录页
- 评论管理页（按作品筛选 + 评论列表 + 删除）

## 7. 验收标准

项目完成时必须满足：

- 网站可以正常打开。
- 首页能展示个人介绍、社交链接、按分类展示作品列表。
- 可以点击作品卡片进入作品详情页。
- 作品详情页能展示作品完整内容。
- 访客可以在作品详情页提交评论。
- 提交后的评论可以立刻展示出来（带高亮动画 + 成功提示条）。
- 管理员可以登录后台。
- 管理员可以按作品筛选评论。
- 管理员可以看到每条评论的时间。
- 管理员可以删除不合适的评论（带二次确认 Modal + Toast 反馈）。
